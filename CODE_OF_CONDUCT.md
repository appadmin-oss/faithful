# Code of conduct

Faithful follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, criticise work rather than people, and make room
for newcomers.

To report unacceptable behaviour, contact the maintainers privately through GitHub
(**Security → Report a vulnerability** works for anything that should not be public). Reports
are handled in confidence.
